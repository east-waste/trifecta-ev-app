# 三連複 2倍回収・期待値最大化シミュレーター

## アプリ概要

頭数と各馬番の単勝オッズを入力すると、Harville法で全三連複の**推定的中確率**と**推定三連複オッズ**を自動生成し、総予算・目標回収倍率・目標払戻許容範囲に基づいて「2倍程度」の回収を狙う買い目と資金配分を提示する Streamlit アプリです。

> 本ツールは、入力された単勝オッズと推定モデルに基づいて、三連複の買い目と資金配分を計算するシミュレーターです。表示される三連複オッズや払戻額は実際のものではなく、モデル上の推定値です。的中や利益を保証するものではありません。実際の投票は自己責任で行ってください。

## クイックスタート（Webアプリの起動方法）

このアプリは Streamlit 製です。次のコマンドを実行すると、ローカルでWebアプリ（ブラウザ画面）が立ち上がります。

```bash

git clone https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>

# 2. 必要ライブラリをインストール（初回のみ）
python3 -m pip install -r requirements.txt

# 3. Webアプリを起動

```

起動すると、ターミナルに次のようなURLが表示されます。

```text
Local URL: http://localhost:8501
```

ブラウザが自動で開かない場合は、表示された `Local URL`（通常 http://localhost:8501 ）を手動で開いてください。
停止するには、ターミナルで `Control + C` を押します。

> メモ: `streamlit` コマンドが見つからない場合は、上記のように `python3 -m streamlit run app.py` を使ってください。PATHを通している場合は `streamlit run app.py` でも起動できます。

## 重要な前提

- 表示される三連複オッズは、実際のJRA等の三連複オッズではありません。
- 表示される払戻額は、実際の払戻額ではなく**モデル上の推定払戻額**です。
- 単勝オッズ、Harville法、補正係数、控除率の仮定に強く依存します。
- 的中や利益を保証するものではありません。

## Harville法による三連複推定

単勝オッズ `O_i` から暫定勝率を計算し、合計が1になるように正規化します。

```text
暫定勝率_i = 1 / O_i
1着確率 p_i = 暫定勝率_i / Σ 暫定勝率_j
```

馬 `i → j → k` の順で1〜3着になる確率を以下で近似します。

```text
P(i,j,k) = p_i × p_j/(1-p_i) × p_k/(1-p_i-p_j)
```

三連複は順不同なので、3頭 `a,b,c` の全6通りを合計します。

```text
三連複(a,b,c)の推定的中確率 = Σ P(i,j,k)
```

## 推定三連複オッズについて

市場側モデルで推定した確率を `q_market`、控除率を `takeout` とします。

```text
推定三連複オッズ = (1 - takeout) / q_market
```

これは実際の三連複オッズではありません。単勝オッズから簡易モデルで逆算した**モデル上の推定値**です。

## 「2倍回収程度」の定義

従来の「推定払戻額 >= 目標払戻額」では、超高オッズの買い目がすべて通ってしまいます。本アプリでは「2倍以上なら何でもOK」ではなく、**目標払戻額に近い範囲**だけを推奨候補にします。

```text
目標払戻額 = 総予算 × 目標回収倍率
```

例:

```text
総予算 = 2,000円
目標回収倍率 = 2.0倍
目標払戻額 = 4,000円
```

さらに、目標払戻許容範囲を設定します。

```text
許容推定払戻下限 = 目標払戻額 × 目標払戻許容下限
許容推定払戻上限 = 目標払戻額 × 目標払戻許容上限
```

初期値:

```text
目標払戻許容下限 = 0.9
目標払戻許容上限 = 1.3
```

総予算2,000円、目標回収倍率2.0倍なら:

```text
許容推定払戻範囲 = 3,600円〜5,200円
```

この範囲内の買い目だけが通常の推奨候補になります。

## 購入額と丸め

理論購入額:

```text
理論購入額 = 目標払戻額 / 推定三連複オッズ
```

実際の推奨購入額:

```text
実際の推奨購入額 = 理論購入額を最低購入単位で切り上げ
```

丸め後のモデル上の推定払戻額:

```text
モデル上の推定払戻額 = 実際の推奨購入額 × 推定三連複オッズ
```

最低購入単位が100円の場合、切り上げによりモデル上の推定払戻額は目標払戻額からズレます。そのズレを「目標払戻との差」として表示します。

## 推奨モード

## 資金配分の方針（予算を使い切る）

推奨買い目は、基本的に**三連複の上位（人気＝高確率／期待値重視モードでは高期待値）から順に**買い、**予算を使い切る**ように配分します。

- 上位の「2倍程度で返る買い目」を、基本購入額で上位から順に買い増します。
- 余った予算は、できるだけ**別の2倍程度の上位買い目を追加購入**して使い切ります（同じ買い目に大きく上乗せして超高配当化させるより、2倍で返る買い目を増やす方がモデル上の期待値が高くなるためです）。
- それでも端数が残る場合のみ、既存の買い目に最低購入単位ずつ上乗せします。ただし、モデル上の推定払戻額が**目標払戻許容上限を超えない範囲**に制限します。
- 候補が極端に少ないなど、2倍程度を保ったままでは使い切れない場合は、無理に超高配当を作らず予算を一部残し、画面に理由と対処（最大買い目数を増やす、許容上限を広げる等）を表示します。

### 1. 2倍回収安定モード

初期値です。目標払戻額に近い買い目を優先し、期待値だけでなく推定的中確率も考慮します。

```text
payout_deviation_ratio = abs(モデル上の推定払戻額 - 目標払戻額) / 目標払戻額
score = expected_value + target_payout * hit_probability - target_payout * payout_deviation_ratio
```

### 2. 期待値重視モード

従来に近いモードです。期待値を最も重視します。ただし、目標払戻許容範囲と推定三連複オッズ上限は守ります。

```text
score = expected_value
```

### 3. 的中率重視モード

推定的中確率を重視します。期待値が極端に悪いものは避けるため、期待値も一部加味します。

```text
score = target_payout * hit_probability + expected_value * 0.3
```

## 人気寄せ具合（旧λ）の意味

画面では以下の2つを調整できます。

- 自分の予想の人気寄せ具合
- 市場オッズ推定の人気寄せ具合

値を大きくすると人気馬をより高く評価します。値を小さくすると穴馬にも確率を分散します。

この2つに差をつけることで、モデル上で割安とみなされる三連複を探します。両者が完全に同じ場合、控除率のぶんだけ期待値はマイナスになりやすくなります。

## 控除率の意味

控除率は、オッズを推定するときに市場全体から差し引かれる割合の目安です。

```text
推定三連複オッズ = (1 - 控除率) / 市場側の推定確率
```

値を大きくすると、推定三連複オッズは低くなります。初期値は `0.25` です。

## 超高オッズを除外する理由

期待値だけを最大化すると、推定的中確率が極端に低い超高オッズ買い目に偏ることがあります。これは「2倍回収程度を狙う」という目的から外れやすいため、初期状態では推定三連複オッズ上限を `200.0` に設定し、それを超える買い目を推奨候補から除外します。

ただし、全三連複候補ランキングには表示され、「オッズ上限超過」列で確認できます。

## バリデーション・警告

- 目標払戻許容下限 < 目標払戻許容上限
- 最低購入単位が正の整数
- 総予算が正の整数
- 最大買い目数が1以上
- 推定三連複オッズ上限が0より大きい
- 単勝オッズが1.0より大きい
- 頭数が3以上
- 推奨候補が0件の場合は理由を表示
- セット全体の推定的中確率が1%未満なら警告
- セット全体の推定的中確率が0.1%未満なら強い警告

## テスト

```bash
python3 -m pytest -q
```

主なテスト対象:

- 目標払戻範囲内の買い目だけが推奨候補になる

- 期待値重視モードで、期待値が高い買い目が優先される
- 的中率重視モードで、的中確率が高い買い目が優先される
